# Галерея виджетов

`WidgetsGalleryNavBtn` использует прежний `WidgetsGallerySideMenu`.
Desktop подключает отдельный `CustomizableWidgetsGalleryNavBtn`. Для него необходимы
`WidgetsGalleryFeature`, `WidgetsGalleryEffects`, `WidgetsGallerySettingsService`
и реализация `WIDGETS_GALLERY_STORAGE`, подключённые через `provideWidgetsGallerySettings()`
в desktop `app.config.ts`.
Admin и mobile используют прежнюю галерею.

`WidgetsGalleryContextHelper` объединяет потоки метаданных, языка и типа дашборда;
обе кнопки используют его для общего контекста. Фильтрация, сортировка и группировка
остаются в `WidgetsGalleryHelper`. Отсутствующий тип для новой кнопки означает
`ClientDesktop`; прежняя кнопка сохраняет фильтрацию по desktop и mobile типам.

## Доступность и представление

`WidgetsGalleryHelper.available` применяет registry приложения, desktop enabled,
исключения типов дашбордов и demo-режим, затем сортирует по `galleryOrder`.
Меню и диалог используют один набор данных. Категории следуют порядку `WidgetCategory`.

- Избранные новые виджеты находятся только в избранном со значком новизны.
- Остальные новые находятся и в «Других», и в «Новых».
- Секция «Новые» выделена приглушённой акцентной рамкой без фона. Молния показана
  в заголовке, а у строк внутри секции и её подменю не повторяется.
- До трёх новых неизбранных виджетов включительно показаны списком, далее — боковым подменю.
- Боковые подменю используют CDK connected overlay с ограничением по viewport,
  список внутри — ng-zorro menu. Поддерживаются стрелки, Home/End и Escape с возвратом фокуса.
- Drawer footer с настройкой не входит в прокручиваемый список.
- Новизна проверяется при открытии галереи; отслеживание истечения даты в реальном времени не требуется.

## Настройки

`WidgetsGallerySettings` содержит `dashboards`, индексированный по `DashboardType`.
Избранное хранится в `favoriteWidgets: FavoriteWidgetPreferences[]`, где каждый объект
содержит `typeId` и может быть расширен дополнительными параметрами. Диалог сохраняет
объекты целиком. Преобразование старого формата настроек не предусмотрено.
Это предпочтения типа дашборда, а не конкретного dashboard guid.
Отсутствующий desktop type нормализуется в `ClientDesktop`. Фильтр типов в UI не показывается.

`WIDGETS_GALLERY_DEFAULTS` определяет начальное избранное desktop:
`instrument-select`, `order-book`, `light-chart`, `tech-chart`, `blotter`,
`order-submit`, `instrument-info`, `news`, `all-instruments`.
Категории «Других» включены, категории избранного выключены. Для остальных типов
начальное избранное пустое. Пустое сохранённое избранное не заменяется дефолтами.

Desktop broker хранит всю конфигурацию в RemoteStorageService под ключом
`widgets-gallery-settings` с `meta.timestamp`. Отсутствие записи возвращает пустую
конфигурацию без записи дефолтов. Ошибка чтения или некорректный формат блокируют
редактирование до успешного повторного чтения. Неизвестные типы и widget IDs сохраняются.
При общем сбросе терминала desktop broker сравнивает `meta.timestamp` записи с
`ApplicationMeta.lastResetTimestamp`: более старые настройки игнорируются, и галерея
использует дефолты для всех типов дашбордов без автоматической записи на сервер.

Диалог редактирует локальный черновик. Только успешный ответ сохранения обновляет
подтверждённое NgRx-состояние и закрывает диалог. При ошибке черновик остаётся открытым.
«Сбросить по умолчанию» заменяет черновик дефолтами текущего типа дашборда;
для применения нужно нажать «Сохранить». «Отмена», крестик и Escape отбрасывают черновик.
Карточки всегда сгруппированы по категориям и имеют высоту 120 px. Название и описание
ограничены двумя строками с многоточием, полный текст доступен при наведении.
Избранное отмечено подсвеченной звездой; её тултип и `aria-label` используют одну
подпись действия добавления или удаления. Ссылки на документацию формирует `HelpService`,
как в заголовках виджетов; при отсутствии ссылки кнопка справки скрыта.
Повторная отправка во время сохранения блокируется. Новая запись независима от
настроек раскладки и действия «Стандартный вид»; миграция старой галереи не требуется.

Метаданные и описания: см. `terminal-widgets-lib/README.md`. Строки UI находятся
в существующем scope `dashboard/widgets-gallery` на ru/en/hy.
